CaveRace history

From a 386 PC to modern desktops.

CaveRace began as an MS-DOS maze-action game inspired by the bomb-based arcade games of its era. Its treasure, aliens, five visual worlds, and ten cave layouts became the foundation for every later release.

1997

The original CaveRace

Created for MS-DOS with 320×200, 256-color VGA graphics, keyboard gameplay, mouse-driven menus, and ten handcrafted caves.

1998

Version 1.2

The preserved MS-DOS release was dated May 1998 and includes the original Map Editor alongside the game.

2002

Version 1.3 for Windows

The first Windows port replaced the DOS graphics, input, and audio systems with DirectX 8.1 while keeping the original campaign.

2026

The caves live on

CaveRace 1.5 restores the original for modern systems, while CaveRace 2 opens a new campaign with 25 handcrafted caves.

Getting started

Run the classics carefully.

Always extract the complete ZIP. Both releases load their level and graphics files from folders beside the executable.

Running version 1.2

Extract the archive, mount its folder in DOSBox or another compatible DOS environment, and run CAVERACE.EXE. The original Map Editor is MAPEDIT.EXE.

Running version 1.3

Extract every file and keep the Levels and Media folders beside CaveRace.exe. A 32-bit Windows virtual machine may be the most reliable option on current systems.
